征引考 · 说明

核验数据来自 CrossRef REST API 与 OpenAlex API，均为公开学术元数据服务。本站不生成、不改写任何字段内容，仅做检索、比对与排版。

「未见」不等于造假。未被收录的中文期刊、会议论文、内部印行资料、网络文献都可能查无记录 —— 请点开「手动检索」到知网、百度学术复核，再下结论。

判定的四档含义

宜引 · 数据源有确切记录，关键字段一致，可直接引用。

需修 · 找到了对应文献，但某个字段（DOI / 年份 / 卷期 / 页码）对不上，需替换。

存疑 · 有相似记录但匹配度不足，可能张冠李戴，需人工确认。

未见 · 两个数据源均无对应记录，可能为编造或未被收录。
